# HHH CRM Phase 2.9.2 – Dark Sidebar & Official Logo

## Thay đổi
- Chuyển toàn bộ sidebar sang nền tối xanh đen thống nhất.
- Chữ, biểu tượng và tiêu đề nhóm điều hướng chuyển sang tông sáng/trắng.
- Mục menu đang chọn giữ nền xanh nổi bật.
- Thay logo chữ HHH bằng logo Hải Hà Hưng do người dùng cung cấp.
- Giữ nguyên khu vực tài khoản, avatar, email/tên, vai trò, cài đặt và nút đăng xuất.
- Khu vực nội dung CRM bên phải vẫn giữ giao diện sáng.

## Cập nhật
- Không cần chạy SQL mới.
- Giữ nguyên cấu hình Supabase hiện tại (`assets/js/supabase-config.js`).
- Giải nén và thay source bằng bản này, sau đó chạy Live Server hoặc push lên GitHub để Cloudflare Pages triển khai.
