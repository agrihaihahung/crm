# HHH CRM – Phase 2.7: Readable Typography

This update builds on Phase 2.6 and increases typography consistently across the CRM: navigation, page titles, descriptions, KPI cards, tables, forms, modal dialogs, status labels, customer profiles, analytics and login.

## Installation
1. Back up your current HHH CRM folder.
2. Extract this package.
3. Copy the contents of `HHH-CRM-Phase2.7` over your current project, or use it as the new project folder.
4. Preserve your existing `assets/js/supabase-config.js` values if they differ from the package.
5. Open `index.html` with VS Code Live Server.

No database migration is required. This is a CSS-only typography update; application logic and Supabase schema are unchanged.
